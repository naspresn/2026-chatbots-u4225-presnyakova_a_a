# Remindly — Telegram-бот для задач

Личный ассистент: принимает и редактирует задачи, сортирует их по приоритету, сроку и категории, напоминает о них и по утрам присылает сводку — каждый день или только в рабочие дни. Умеет искать задачи, показывать и очищать историю выполненных, выгружать и загружать задачи в файле для Excel и считать сроки в рабочих днях по производственному календарю.
Интерфейс на русском, часовой пояс Europe/Moscow. Данные хранятся в базе SQLite.

## Запуск

1. Нужен Python 3.10 или новее.
2. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
3. Установите зависимости (лучше в виртуальном окружении):

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate        # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` из примера и впишите токен в `BOT_TOKEN`:

   ```bash
   cp .env.example .env
   ```

5. Запустите бота:

   ```bash
   python bot.py
   ```

Остановить бота можно сочетанием `Ctrl+C`.

При первом запуске бот создаёт базу `tasks.db`. Если рядом лежит старый `tasks.json` (из lab1), задачи, напоминания и настройки из него автоматически переносятся в базу, а файл переименовывается в `tasks.json.migrated` — данные из него не удаляются.

### Настройки в `.env`

| Переменная | Зачем | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен бота от @BotFather | — (обязательно) |
| `DB_FILE` | файл базы SQLite | `tasks.db` рядом с `bot.py` |
| `DATA_FILE` | старый `tasks.json` для переноса в базу | `tasks.json` рядом с `bot.py` |
| `CALENDAR_URL` | адрес производственного календаря | `https://isdayoff.ru/api/getdata` |

Относительные пути считаются от папки бота.

Чтобы проверить, как бот работает без календаря, поставьте в `.env` неверный адрес, например `CALENDAR_URL=https://isdayoff.ru/api/nothing`, и перезапустите бота: он будет считать выходными только субботу и воскресенье и напишет об этом в ответах.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Приветствие, включает ежедневную сводку |
| `/help` | Список команд с примерами |
| `/add` | Добавить задачу: текст → приоритет → срок → категория |
| `/add Купить хлеб` | То же, но текст указан сразу |
| просто текст | Бот предложит сохранить его как задачу |
| `/list` | Все активные задачи (сначала просроченные, затем по приоритету и сроку) и кнопки фильтров |
| `/list высокий`, `/list рабочие`, `/list неделя` | Сразу с фильтром: по приоритету, по категории, на ближайшую неделю |
| `/today` | Задачи на сегодня и просроченные |
| `/find отчёт` | Найти задачи по слову (без слова бот спросит, что искать) |
| `/history` | Последние 10 выполненных задач и кнопки «Очистить всё», «Старше 30 дней» |
| `/edit` | Выбрать задачу кнопками и изменить текст, приоритет, срок или категорию |
| `/edit 3` | Изменить задачу #3 |
| `/done` | Выбрать задачу кнопками и отметить выполненной |
| `/done 3` | Отметить задачу #3 выполненной |
| `/delete` | Выбрать задачу кнопками и удалить (с подтверждением) |
| `/delete 3` | Удалить задачу #3 (с подтверждением) |
| `/remind` | Выбрать задачу кнопками, затем вариант напоминания |
| `/remind 3` | Варианты напоминания для задачи #3 |
| `/remind 3 18:30` | Напомнить сегодня в 18:30, а если это время прошло, то завтра |
| `/remind 3 14.10 18:30` | Напомнить в указанный день |
| `/reminders` | Задачи с напоминаниями: время и выбранный вариант, ближайшие первыми |
| `/digest` | Настройки сводки и кнопки «Каждый день» и «Только в рабочие дни» |
| `/digest on` / `/digest off` | Включить или выключить сводку |
| `/digest 08:30` | Изменить время сводки (по умолчанию 09:00) |
| `/digest рабочие` / `/digest каждый день` | Сводка только в рабочие дни / каждый день (по умолчанию — каждый день) |
| `/categories` | Категории и сколько в них задач; свои категории можно переименовать и удалить кнопками |
| `/stats` | Статистика по задачам |
| `/export` | Прислать файл со всеми задачами (CSV, открывается в Excel) |
| `/import` | Подсказать формат и загрузить задачи из присланного CSV-файла |
| `/workdays` | Сколько рабочих дней осталось до конца месяца |
| `/cancel` | Прервать текущий диалог |

Срок вводится как `ДД.ММ` или `ДД.ММ.ГГГГ`. Для даты без года бот выбирает ближайшую к сегодняшнему дню, в этом или следующем году: 20 декабря «10.01» — это 10 января следующего года. Это правило работает и в `/remind`. Дату в прошлом бот примет, но предупредит, что задача сразу просрочена.

На вопросы с кнопками можно отвечать текстом, регистр, лишние пробелы и точка в конце не важны:
- «Сохранить как задачу?» и подтверждение `/delete`: «да», «ок», «добавить» или «нет», «отмена»;
- приоритет: «высокий», «средний», «низкий»;
- срок: «сегодня», «завтра», «без срока», сразу дата или «через 5 рабочих дней»;
- категория: название из списка (с опечатками), «без категории», «нет» или новое название — оно сохранится;
- выбор задачи: номер («3»), а для `/remind` сразу номер и время («3 18:30», «3 14.10 18:30»);
- подтверждение `/delete`: ещё «удалить» (= да) и «оставить» (= нет);
- вариант напоминания: текст кнопки («за сутки», «через час»), полное название («за сутки до срока»), «завтра», «нет», «не надо», либо сразу время («18:30», «14.10 18:30»);
- «Такая задача уже есть… Всё равно создать?»: «да», «создать» или «нет», «отмена» (при редактировании — ещё «сохранить»);
- «Что изменить?» в `/edit`: «текст», «приоритет», «срок» (или «дата»), «категория»;
- «Что сделать с категорией?» в `/categories`: «переименовать», «удалить» или «назад»; подтверждение удаления: «да», «удалить» или «нет», «оставить»;
- «Что убрать из истории?»: «всё» или «старше 30 дней» («старые»); подтверждение очистки: «да», «очистить» или «нет».

Любая команда, кроме `/add` и `/cancel`, посреди диалога молча завершает его и выполняется как обычно. Диалог без ответа завершается через 10 минут.

### Редактирование задач

`/edit 3` (или текстом «изменить 3», «редактировать 3») показывает задачу и спрашивает «Что изменить?» с кнопками «Текст», «Приоритет», «Срок», «Категория». Без номера бот сначала покажет задачи кнопками, как в `/remind`.

Дальше — те же шаги, что при добавлении задачи: кнопки приоритета, срока (в том числе «Через N рабочих дней» и предупреждение о выходном или празднике), список категорий или своя категория. Если новый текст совпадает с другой активной задачей, бот переспросит: «Такая задача уже есть… Всё равно сохранить?». Изменить можно только активную задачу.

После изменения бот показывает обновлённую задачу:

```
✏️ Задача #3 изменена: 🔴 Подготовить отчёт · 🏷 Рабочие · до 15.12
⏰ Напоминание перенесено: 14.12 в 10:00 (за сутки до срока).
```

Напоминание, поставленное относительно срока («в день срока», «за сутки», «за неделю», «за месяц до срока»), при смене срока переносится на новую дату. Если для нового срока это время уже прошло или срок убран, напоминание снимается, и бот об этом пишет. Остальные напоминания («через час», своё время) не меняются.

### Категории

После выбора срока бот спрашивает: «Категория задачи? Выберите из списка или напишите свою». В списке базовые категории («Рабочие», «Бытовые», «Учебные», «Личные»), категории, которые вы создали сами, и кнопка «Без категории».

- Новая категория, написанная текстом, сохраняется («🏷 Новая категория «Дача» сохранена») и дальше появляется в списке. Первая буква становится заглавной, длина — до 30 символов.
- Если написать существующую категорию с другим регистром или небольшой опечаткой («рабчие»), бот выберет её, а не создаст новую.
- Категория видна в списках: «#3 🔴 Подготовить отчёт · 🏷 Учебные · до 04.11».

### Управление категориями

`/categories` (или текстом «категории») показывает все категории и сколько в каждой задач — активных и выполненных:

```
🏷 Категории

Базовые (не меняются):
• Рабочие — 1 задача
• Бытовые — нет задач
…

Ваши:
• Дача — 2 задачи, активных 1
• Спорт — нет задач

Без категории — 1 задача
```

Под списком — кнопки ваших категорий. Нажмите на категорию, и бот предложит «✏️ Переименовать», «🗑 Удалить» или «⬅️ Назад». Базовые категории («Рабочие», «Бытовые», «Учебные», «Личные») кнопок не получают и не меняются.

- **Переименовать:** бот спросит новое название и поменяет категорию во всех задачах, в том числе выполненных («✏️ Категория «Дача» переименована в «Загородный дом». Изменено задач: 2»). Название, которое уже занято (например, «Рабочие»), бот не примет и попросит другое.
- **Удалить:** перед удалением бот спрашивает подтверждение и пишет, сколько задач в категории: «🗑 Удалить категорию «Дача»? В ней 2 задачи, активных 1 — они перейдут в «Без категории»». После удаления задачи остаются, но без категории.
- После переименования или удаления бот снова показывает обновлённый список, так что можно продолжить.
- Кнопки списка работают и позже, и посреди другого диалога (он молча завершается). Если категорию уже удалили, бот так и скажет.

### Срок в рабочих днях и производственный календарь

На шаге срока есть кнопка «Через N рабочих дней»: бот спросит число и посчитает дату по производственному календарю [isdayoff.ru](https://isdayoff.ru) — с учётом выходных, праздников и переносов. То же можно написать сразу: «через 5 рабочих дней».

- Если срок выпадает на выходной или праздник, бот предупреждает: «⚠️ 04.11 (ср) — праздник, нерабочий день». Срок при этом сохраняется.
- `/workdays` (или «рабочие дни») — сколько рабочих дней осталось до конца месяца и сколько их всего в месяце.
- Календарь на год загружается одним запросом и хранится в памяти 12 часов.
- Если календарь недоступен (нет интернета, сервис не отвечает, неверный адрес в `.env`), бот не ломается: выходными считает только субботу и воскресенье и пишет: «⚠️ Производственный календарь сейчас недоступен — выходными считаю только субботу и воскресенье, праздники не учитываю». Повторная попытка — через 5 минут.

### Фильтры списка

Под `/list` есть кнопки: «🔴 Высокий», «🟡 Средний», «🟢 Низкий», «📅 Неделя» и «🏷 Категории» (покажет категории, в которых есть задачи, с их количеством). «📋 Все задачи» снимает фильтр.

- «Неделя» — задачи со сроком в ближайшие 7 дней, включая сегодня; просроченные тоже попадают сюда.
- Фильтр можно написать сразу: `/list рабочие` или текстом «список рабочие», «список высокий», «список неделя», «список без категории».

### Поиск и история

- `/find отчёт` или «найти отчёт» ищет слово в тексте и категории задач — и активных, и выполненных, без учёта регистра и «ё». Можно несколько слов: найдутся задачи, где есть все.
- Если точных совпадений нет, бот ищет слова с небольшими опечатками (по тем же правилам, что и для команд).
- Если по «найти ключи» ничего не нашлось, бот подскажет, как добавить это задачей: `/add найти ключи`.
- `/history` или «история» — последние 10 выполненных задач с датой выполнения; выполненные позже срока помечены.

### Очистка истории

Под списком `/history` есть кнопки «Очистить всё» и «Старше 30 дней». Перед очисткой бот спрашивает «Убрать из истории … (5)? В /stats они останутся.» с кнопками «Да» и «Нет» — ответить можно и текстом. То же текстом: «очистить историю» (бот спросит, что убрать) или «очистить всю историю»; со слешем — `/clear_history`.

Задачи при очистке не удаляются из базы, а получают пометку `archived`: они пропадают из `/history` и `/find`, но `/stats` продолжает их учитывать, поэтому статистика не обнуляется. В выгрузке `/export` они тоже остаются.

### Утренняя сводка

По умолчанию сводка приходит каждый день в 09:00. `/digest` показывает текущие настройки и кнопки «Каждый день» и «Только в рабочие дни» (выбранный режим отмечен ✅; выбор режима заодно включает сводку). Текстом: «сводка рабочие» и «сводка каждый день».

В режиме «Только в рабочие дни» бот перед отправкой проверяет сегодняшний день по производственному календарю и в выходные и праздники сводку не присылает. Если календарь недоступен, нерабочими считаются только суббота и воскресенье.

### Выгрузка и загрузка задач

`/export` присылает файл `remindly_ГГГГ-ММ-ДД.csv` со всеми задачами. Формат — как в `data/sample_tasks.csv`:

```
номер;задача;приоритет;категория;срок;статус;создана;выполнена
1;Подготовить отчёт по лабораторной работе №2;высокий;Учебные;20.10.2026;активна;;
```

Файл в кодировке UTF-8 с BOM и с разделителем «;» — так его сразу правильно открывает Excel с русскими настройками.

`/import` объясняет формат; задачи загружаются из CSV-файла, присланного в чат (можно прислать и без команды):

- обязательна только колонка «задача», порядок колонок любой, разделитель «;» или «,», кодировка UTF-8 или Windows-1251 (обычный «CSV» из Excel);
- приоритет — высокий, средний или низкий (пусто — средний); статус — активна или выполнена (пусто — активна); даты — ДД.ММ.ГГГГ;
- номера из файла не используются — задачи получают новые номера; новые категории сохраняются;
- задачи, которые уже есть (тот же текст, срок и статус), повторно не добавляются — один и тот же файл можно загрузить дважды без дублей;
- строки с ошибками пропускаются, бот перечисляет их с причиной: «строка 4: неизвестный приоритет «срочно» — нужно: высокий, средний или низкий», «строка 5: несуществующая дата срока «31.02.2026»», «строка 6: неверный формат даты срока «2026-10-28» — нужно ДД.ММ.ГГГГ»;
- файл Excel (.xlsx) бот не читает и подскажет сохранить его как CSV. Ограничения: до 1 МБ и до 1000 строк.

Ячейки, которые начинаются с `=`, `+`, `-` или `@`, при выгрузке получают апостроф впереди, чтобы Excel не принял текст задачи за формулу; при загрузке апостроф убирается.

### Выбор задачи кнопками

Если `/done`, `/delete`, `/remind` или `/edit` отправлены без номера (в том числе текстом: «готово», «удалить», «напомни», «изменить»), бот показывает активные задачи кнопками в порядке `/list`, не больше 10. На кнопке номер и начало текста задачи до 30 символов: «#4 Подготовить отчёт по лаборато…». Вместо нажатия можно написать номер задачи, а для `/remind` — сразу номер и время: «1 11:43».

### Напоминания

После выбора задачи в `/remind` бот всегда показывает полный набор вариантов, по две кнопки в ряд, «Не напоминать» — отдельной строкой внизу:

| Задача | Варианты |
|---|---|
| любая | «Через час», «Завтра в 10:00», «Через неделю» |
| со сроком, дополнительно | «В день срока», «За сутки», «За неделю», «За месяц» — до срока, в 10:00 выбранного дня |
| любая | «Указать время» (ЧЧ:ММ или ДД.ММ ЧЧ:ММ), «Не напоминать» |

- На кнопках короткие подписи: Telegram делит строку поровну и не даёт задать ширину кнопок, поэтому длинные названия обрезались бы. Под вопросом бот пишет «Варианты «за …» — до срока», а в подтверждении, `/reminders` и предупреждениях — полное название: «(за сутки до срока)».
- «За сутки» — накануне срока, «за неделю» — за 7 дней, «за месяц» — в то же число предыдущего месяца, а если такого числа нет, в последний день месяца (для срока 31.03 — 28.02).
- Если выбрать вариант, время которого уже прошло, бот оставит кнопки и напишет: «Время для варианта «За неделю до срока» уже прошло (06.10 в 10:00). Выберите другой вариант».
- Если у задачи нет срока, а написать «за сутки», бот ответит, что срока нет, и попросит выбрать другой вариант.
- Подтверждение: «⏰ Напомню о задаче #1 31.10 в 10:00 (за сутки до срока)». Тот же вариант виден в `/reminders`.
- У задачи одно напоминание: новое заменяет старое. «Не напоминать» снимает уже поставленное.
- Старая форма `/remind 3 18:30` и `/remind 3 14.10 18:30` работает как раньше.

### Напоминание при добавлении

После добавления задачи бот сразу спрашивает «Напомнить о задаче?» с теми же вариантами. «Не напоминать» завершает диалог. Если вместо ответа написать новую задачу или команду, вопрос молча закрывается, а сообщение обрабатывается как обычно.

### Повторяющиеся задачи

Если текст новой задачи совпадает с одной из активных задач (без учёта регистра, лишних пробелов и знаков препинания в конце), бот сразу после ввода текста спрашивает: «Такая задача уже есть: #7 🟢 Тест · до 13.10. Всё равно создать?» с кнопками «Создать» и «Отмена». «Создать» продолжает добавление (приоритет, срок), «Отмена» завершает диалог: «Ок, не создаю». Проверка работает для `/add`, `/add <текст>` и быстрого добавления; при быстром добавлении этот вопрос заменяет «Сохранить как задачу?». С выполненными задачами текст не сравнивается.

### Команды обычным текстом

Команды можно писать без слеша, регистр не важен:

| Текст | Команда |
|---|---|
| «список», «лист», «задачи», «мои задачи» | `/list` |
| «список рабочие», «список высокий», «список неделя», «список без категории» | `/list` с фильтром |
| «сегодня», «на сегодня» | `/today` |
| «найти», «найти отчёт» (и «найди», «поиск») | `/find`, `/find отчёт` |
| «категории», «мои категории» | `/categories` |
| «история», «выполненные» | `/history` |
| «очистить историю», «очистить всю историю» | очистка истории (`/clear_history`) |
| «экспорт», «выгрузить» | `/export` |
| «импорт», «загрузить» | `/import` |
| «рабочие дни» | `/workdays` |
| «напоминания» | `/reminders` |
| «статистика» | `/stats` |
| «помощь», «команды» | `/help` |
| «сводка», «сводка вкл», «сводка выкл», «сводка 08:30» | `/digest`, `/digest on`, `/digest off`, `/digest 08:30` |
| «сводка рабочие», «сводка каждый день» | `/digest рабочие`, `/digest каждый день` |
| «добавить», «добавить Купить хлеб» | `/add` |
| «готово», «выполнено», «сделано» | `/done` (выбор задачи кнопками) |
| «готово 3», «выполнено 3», «сделано 3» | `/done 3` |
| «удалить» | `/delete` (выбор задачи кнопками) |
| «удалить 3» | `/delete 3` |
| «изменить», «редактировать» | `/edit` (выбор задачи кнопками) |
| «изменить 3», «редактировать 3» | `/edit 3` |
| «напомни» | `/remind` (выбор задачи кнопками) |
| «напомни 3» | `/remind 3` (варианты напоминания) |
| «напомни 3 18:30», «напомни 3 14.10 18:30» | `/remind 3 18:30`, `/remind 3 14.10 18:30` |
| «отмена» | `/cancel` |
| «привет», «приветик», «здравствуй(те)», «добрый день», «доброе утро», «добрый вечер», «хай», «салют», «hi», «hello», «начать», «старт» | `/start` |

Текст считается командой, только если всё сообщение совпадает с одним из вариантов. «Список покупок» или «Сегодня позвонить маме» — это задачи, и бот предложит их сохранить. «Список <фильтр>» — команда, только если после «список» стоит приоритет, «неделя» или одна из ваших категорий. Исключение — «найти …»: любое сообщение, которое начинается с «найти», бот считает поиском (если ничего не найдено, он подскажет, как добавить это задачей).

Посреди диалога сначала проверяется ответ на текущий вопрос: «сегодня» на шаге срока выбирает срок, «рабочие дни» там же — срок в рабочих днях, а «добавить» в ответ на «Сохранить как задачу?» означает «да». Если это не ответ, но текстовая команда, она работает как команда со слешем: диалог завершается, команда выполняется. Исключения — шаги, где подходит любой текст: «Напишите текст задачи» и «Что найти?» (команды проверяются первыми, иначе «отмена» стала бы задачей или запросом), а на шаге категории сначала ищется существующая категория, затем команда, и только потом создаётся новая категория.

### Опечатки

Ответы на вопросы и текстовые команды распознаются с небольшими опечатками: «звтра» → «завтра», «срдений» → «средний», «спсок» → «список». Бот не переспрашивает, исправленное значение видно в подтверждении, например «срок 13.10».

Опечатки считаются с учётом раскладки ЙЦУКЕН:
- одна опечатка — пропущенная или лишняя буква («звтра»), две соседние буквы переставлены местами («срдений») или нажата соседняя клавиша («зпвтра»: «п» рядом с «а»);
- буква, заменённая на далёкую клавишу, считается за две опечатки. Поэтому «помочь» не путается с «помощь» (клавиши «ч» и «щ» далеко), а «задача» — с «задачи».

Сколько опечаток допускается:
- слова до 4 букв («да», «нет», «ок», «лист», «вкл») — только точное совпадение;
- слова из 5–7 букв — одна опечатка;
- слова от 8 букв — до двух опечаток.

Буква «ё» приравнивается к «е».

Если опечатка делает слово похожим на два варианта сразу, бот его не угадывает. Номера, даты и время должны быть написаны точно.

В `/stats` процент «в срок» считается по выполненным задачам, у которых был срок: задача выполнена в срок, если её закрыли не позже дня срока.

## Хранение данных

Данные лежат в базе SQLite `tasks.db` рядом с `bot.py` (путь меняется переменной `DB_FILE`). Все запросы к базе собраны в классе `Database` в `bot.py`.

| Таблица | Что хранит |
|---|---|
| `users` | пользователи: `chat_id`, следующий номер задачи, включена ли сводка, её время и режим (`daily` — каждый день, `workdays` — только в рабочие дни) |
| `tasks` | задачи: номер, текст, приоритет, категория, срок, время напоминания и выбранный вариант («за сутки до срока»), статус, даты создания и выполнения, пометка `archived` — убрана из истории |
| `categories` | свои категории пользователя (базовые заданы в коде); при переименовании и удалении категории меняются и задачи в ней |
| `meta` | служебные отметки, например что перенос из `tasks.json` уже был |

- Задачи каждого пользователя хранятся отдельно по `user_id`; пользователь видит и меняет только свои задачи.
- Номера задач (1, 2, 3…) у каждого пользователя свои и не меняются после удаления других задач.
- Каждое изменение сразу записывается в базу в транзакции; загрузка из файла — одной транзакцией (либо все задачи, либо ни одной).
- Поиск без учёта регистра сделан функцией `norm()`, подключённой к SQLite из Python: встроенная `LOWER()` в SQLite понимает только латиницу.
- После перезапуска бот восстанавливает из базы все напоминания и сводки. Напоминание, время которого прошло, пока бот был выключен, придёт сразу после запуска.
- Если база создана прошлой версией бота, при запуске в неё автоматически добавляются новые колонки (`digest_mode`, `archived`); данные сохраняются.
- Перенос из `tasks.json` выполняется один раз: при первом запуске, если файл есть. После переноса файл переименовывается в `tasks.json.migrated`, а в таблице `meta` ставится отметка. Если перенос не удался (повреждённый файл), бот пишет об этом в лог и оставляет файл как есть.

Посмотреть базу можно любой программой для SQLite, например:

```bash
sqlite3 tasks.db "SELECT id, text, category, due, status FROM tasks"
```
