# 2026-chatbots-u4225-presnyakova_a_a

Репозиторий с лабораторными работами по курсу [Vibe Coding: AI-боты для бизнеса](https://github.com/itmo-ict-faculty/vibe-coding-for-business).

Университет ИТМО, факультет ФИКТ, 2026/2027 учебный год.  
Студент: Преснякова Анастасия Алексеевна, группа U4225.

## О курсе

В курсе создаются Telegram-боты для бизнес-задач с помощью LLM. Код генерируется по промптам.

## Лабораторные работы

| № | Тема | Папка | Статус |
|---|---|---|---|
| 1 | Создание первого Telegram-бота без программирования | [lab1](lab1) | выполнена |
| 2 | Подключение бота к данным | [lab2](lab2) | выполнена |
| 3 | Деплой бота и сбор обратной связи | [lab3](lab3) | в работе |

В каждой папке находится отчёт `labN_report.md`: описание задачи, промпты, стек технологий, скриншоты, трудности и выводы.

## Структура репозитория

```
labN/
├── bot/              код бота, зависимости, инструкция по запуску
├── images/           скриншоты для отчёта
└── labN_report.md    отчёт по лабораторной работе
```
